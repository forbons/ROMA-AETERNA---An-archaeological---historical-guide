# ROMA AETERNA - An archaeological & historical guide
This project aims to create a comprehensive guide to the city of Rome in Italy. Over some time, I will gather information about various sights in and around the city here. There will be a focus on archaeological and historical topics, so far I decided on the following categories:

1. Archaeological sites
2. Churches
3. Museums & Collections
4. Palazzi
5. Torre
